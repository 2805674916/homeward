# 归途搜索的数学模型与完备性分析

## 1. 候选段模型

**候选段** e = (j, r, q, a, b)：车次 j 实际乘坐 r→q，购票区间 a→b，约束

- `a ≤ r < b`：票面覆盖实际上车站，保证能上车；
- 区间当前可直接购买：`buy=Y` 且各席别可买张数合计 ≥ 人数（"有"视为充足，候补/0/无不可购）。

| 类型 | 条件 | 含义 |
|---|---|---|
| 正常票 | a=r, b=q | 票面即乘坐区间 |
| 买短乘长 | b < q | b→q 车上补票；补票费无公开接口，不计总价 |
| 买长乘短 | a < r 或 b > q | 票面覆盖上车站 / 提前下车差价不退 |
| 买长又买短 | a < r 且 b < q | 两者叠加 |

段的实际出发/到达取乘坐区间 r→q 的时刻；费用 = 购票区间 a→b 按可购席别的最低公布票价。

**乘车图** G = (V, E)：边来自查询 q(date, u, v)。12306 对同城查询合并返回，一条查询可产生从簇内任一站出发的边，邻接表按实际发站键存取。

**换乘约束** `dep(e2) − arr(e1) ≥ τ(kind)`：

| kind | 条件 | τ | 计入换乘数 |
|---|---|---|---|
| 同车分段 | 同 train_no 且车站相接 | 2 分钟 | 否 |
| 同站换乘 | e2.u = e1.v | 15 分钟 | 是 |
| 跨站换乘 | 同城簇（≤约 20km） | 40 分钟 | 是 |
| 其余 | — | ∞（禁止） | — |

**路径约束**：换乘数 ≤ K（默认 3，同车分段不计），首段实际出发 ≥ T_min，末段实际到达 ≤ T_max，
同车分段受段数上限 K+3 约束。

## 2. 算法分层与完备性

枚举分四层，全部在同一候选段语义下：

1. **直达扫描**：查询 (o,d) 出发日+次日窗口，正常票直达。
2. **走廊图 BFS**：边集无条件覆盖 {o}×H、H×{d} 与枢纽相邻走廊窗口（corridor[idx+1:idx+4]）；
   BFS 状态携带"已用换乘数 k"，只在更换车次时 k+1，同车分段靠段数上限约束；
   边装载时把窗口/截止内但容量不足的行存入售罄池备用。
   **定理**：凡边集已装载的 (u,v) 上任何满足换乘约束与时间窗的路径都会被枚举。
   1 次换乘路径只依赖 o×H 与 H×{d} 两类无条件边，因此 1 次换乘是完备的；
   2–3 次换乘依赖走廊窗口与预算（预留 EDGE_RESERVE=110）未被截断。
3. **直达拆票**：对售罄直达车按停站序列有界枚举购票区间
   （补最后一小段 / 下一站买长 / 前站保上车站 / 买到终点 / 中点短买 / 组合，每车 ≤8 区间、≤8 车），
   每个候选 1 次查询，命中即构成买短乘长 / 买长乘短 / 买长又买短方案。
4. **中转链救援**：对售罄的 o→h / h→d 边按同样区间尝试拆票，与已装载的另一半链组合成一程中转。

**Pareto 过滤**：按 (票价, 历时, 换乘数, 补票标志) 剔除被支配方案；
未核价方案不与已核价方案互比——真实价格未知，不能断言其被支配。

**容量语义**：`has_seat` 按"可买张数合计 ≥ 人数"判定，不同席别可拆单购买；单人时退化为旧语义。

## 3. 剩余缺漏（明示）

- 拆票枚举是有界的：直达拆票每车 ≤8 个购票区间、≤8 列车；链救援只覆盖一程中转首/末边售罄；
  "2 次及以上换乘 + 拆票"的组合不枚举。完整模型需要每列车每对停站的 cap/fare = O(停站数²) 查询，
  在防风控预算内不可行，此处是工程取舍。
- H 是有限集（默认 14）：时刻表高频 ∪ 走廊地理候选；不在 H 的中间站不可经停。
- 补票费 supp_fare 无 12306 公开接口：买短乘长/买长又买短方案不出总价，仅列补票区间并标注风险。
- 候补按"仅当前可直接购买"语义排除；退票回流是概率事件，不做预测。
- 查询硬上限（默认 260，含核价预留 50）下，各层按优先级截断。

## 4. 复杂度

边查询 ≈ 2·(2|H| + 3|H|) = O(|H|)；拆票 ≤ 8 车 × 8 区间；救援 ≤ 24 次；核价 = 唯一票段数。
总量受 `--max-queries`（默认 260）硬约束，串行限速 3 秒/次，全程约 15 分钟。
