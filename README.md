# 归途 · The Way Home

一张火车票，装下回家的距离。**归途**是一个可安装的火车出行规划 skill：输入出发地、目的地、日期、最早出发时间、到达时限、人数和预算，生成带中文省界、换乘节点和逐段车次的**单文件离线 HTML 报告**。诗意文案与渡船、车票插画均为原创，不引用《乡愁》原文。

## 它解决什么痛点

- **“直达没票”不等于“回不了家”**：在候选铁路走廊内组合直达和最多三次换乘，按实际到发时间与换乘缓冲筛掉赶不上的方案。
- **一张截图看不清怎么买**：每段列出车次、上车站、下车站、乘车日期、可买席别和换乘站；地图把站点编号与车次索引对应起来。
- **价格常被错误低估**：同一票段只核价一次，复用到多个方案；只用有余票席别对应的报价。缺价就写“待核价”，不会拿二等座价格冒充商务座价格。
- **拆票思路难以比较**：将直达、中转、买短乘长和买长乘短分开呈现，明确车上补票的风险及提前下车不退差价。
- **分享方案不想部署服务**：报告将样式、地图和数据打入单个 HTML，可离线打开、筛选和按价格、到达时间、历时、舒适度排序。

> 非 12306 官方服务；不代购。余票、票价、时刻以 12306 为准。地图线路是站点间地理示意，不是实际铁轨。买短乘长补票可能失败；候选走廊与查询额度限制下，不保证穷尽全国车次。

## 作为 skill 使用

项目自带 `.agents/skills/train-plan/SKILL.md` 与完整的 `scripts/`、`assets/`、`references/`。支持该目录约定的工具可直接加载项目级 skill；如需个人全局使用，可将 `.agents/skills/train-plan/` 复制到用户目录下对应的 skills 位置。不要同时保留两个不同版本的同名 skill。包内包含已校验的 geoBoundaries Public Domain 省界；首次查询时才下载站名表到忽略的 `.cache/`。示例数据不含真实个人行程。

## 体验演示

Python 3.10+，不需要第三方 Python 包。运行：

```bash
python render.py examples/demo.json demo.html
```

直接打开 `demo.html`。示例使用虚构车次、空票价，不代表真实可买。未安装省界时，地图明确标为“站点示意”。

## 可选：安装省级边界

```bash
python prepare_map.py
```

源码根目录默认不追踪下载地图，安装脚本会自动读取系统代理设置（本地 SOCKS5 等）并从 geoBoundaries 的 CHN/ADM1 gbOpen 版本下载标注为 **Public Domain** 的简化 GeoJSON，SHA-256 校验成功后写入 `assets/china_adm1.geojson`。本次已在本机通过系统代理安装，完整 skill 分发包内含校验后的省界。单独复制源码时若未安装，仍能生成明确标注的站点示意图。校验 SHA-256 为 `bc4afc7eacf4351ae5b3ae7a612327987ce1123cb5deb8574fb49107091c6623`。公共展示地图前仍需核对当地地图展示要求。

## 查询并生成报告

需要 `curl` 和可访问的 12306。首次运行会从 12306 获取站名表并缓存在 `.cache/`，不在仓库分发。程序串行限速、缓存与退避，请勿并发或频繁重跑。

```bash
python search.py --from-city 上海 --to-city 武汉 --date YYYY-MM-DD \
  --after 18:00 --arrive-by "YYYY-MM-DD 12:00" \
  --people 2 --budget 800 --max-transfers 3 --max-queries 260 --out my-trip.html
```

把日期替换为 12306 可查询的实际日期。`search.py --out` 一次生成报告。搜索按候选段模型枚举：直达与最多三次换乘（同车分段 2 分钟且不计换乘次数）、售罄直达车的拆票尝试（买短乘长/买长乘短/买长又买短/前站保上车站）、以及首末段售罄一程中转的拆票救援；余票按"可买张数合计 ≥ 人数"核验（不同席别可拆单）；输出经 Pareto 过滤。票价按唯一票段去重查询并复用，全部票段有对应可买席别报价才显示全程合计，否则显示"待核价"，绝不按里程臆测；无座票价按同席别公布票价核出（动车组二等座/普速硬座）；补票区间按 12306 同车公布票价给出参考价（无座，带 * 标注）。查询默认 260 次、串行 3 秒/次，全程约 15 分钟；低于 180 会明显削弱中转搜索。

## 目录

- `search.py`、`fares.py`：候选路径、时序换乘、拆票尝试、去重核价。
- `lib12306.py`：串行请求、限速、缓存及运行时站名表。
- `render.py`、`base.css`、`design.css`：生成单文件报告，嵌入 CSS、SVG 和可选省界。
- `coords.py`：近似站点经纬度，供地理示意使用。
- `prepare_map.py`：安装并校验 Public Domain 省界文件。
- `examples/demo.json`、`tests/`：虚构演示与回归测试。

运行 `python -m unittest discover -s tests -v` 验证。发布前检查 `git status`；`.gitignore` 排除缓存、下载的数据和生成的个人行程 HTML。不要把本地生成的真实行程报告提交到公共仓库。

## 限制

拆票尝试是有界枚举（每售罄直达车 ≤8 个购票区间、≤8 列车；链救援覆盖一程中转首末边），不是所有停站区间的穷举；"多次换乘 + 拆票"组合不枚举。候选枢纽（默认 14 个）、余票接口状态与查询预算都可能让方案漏检。车上补票可能失败且无座；补票费无公开接口，不计入总价。报告不是购票承诺，也不是持续监控。模型与完备性边界详见 `references/math.md`。
